--- Model specification (both measures) ---
Fitted with mgcv::bam(), fREML, discretised covariates. Each model: an
ordered-factor parametric term (condition) + a reference smooth s(time) +
an ordered-factor difference smooth s(time, by=conditionO), plus by-item
random intercepts and by-participant random REFERENCE and DIFFERENCE
factor smooths (Soskuthy 2021, within-item recommendation). An AR(1)
error model corrected residual autocorrelation.
  F0 model:        family = scat, factor-smooth basis = cr, AR(1) rho = -0.038
  Intensity model: family = gaussian, factor-smooth basis = cr, AR(1) rho = 0.394

--- Ready-to-adapt METHODS paragraph ---
F0 and intensity contours were analysed with generalized additive mixed
models (GAMMs) using the mgcv package (Wood, 2017) in R, following the
strategies evaluated by Soskuthy (2021) and Wieling (2018). Each contour
measure was modelled over a per-syllable normalised time index (each
syllable mapped to one unit so boundaries align across tokens) with a
reference smooth and an
ordered-factor difference smooth contrasting the present/paroxytone and
past/oxytone conditions. The random-effects structure comprised by-item
random intercepts and by-participant random reference and difference
factor smooths (penalised thin-plate/cubic-regression bases, m = 1),
which capture participant-specific contour shapes and participant-specific
realisations of the condition contrast. Residual autocorrelation was
addressed with a first-order autoregressive (AR1) error model, with rho
set to the lag-1 residual autocorrelation of an otherwise identical model.
Models were estimated with fast restricted maximum likelihood (fREML) and
discretised covariates. The factor-smooth basis (thin-plate vs cubic
regression) was selected by AIC. Heavy-tailed F0 residuals were
accommodated with a scaled-t family. The presence of a condition
difference was tested both via a combined binary difference smooth and via
separate tests of the parametric (height) and smooth (shape) difference
terms; for the latter, a Bonferroni-corrected alpha of .025 was used.
